## 💻 How to Run Locally

You can open `index.html` directly in any web browser, or launch a lightweight local server:

### Using Python:
```bash
python -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.

### Using Node.js (npx):
```bash
npx serve .
```

## 🌐 Deployment Options

Because this site is 100% static (HTML/CSS/JS with zero build dependencies), it can be deployed in minutes to any hosting provider:

- **Hostinger / cPanel**: Upload all files to `public_html/`.
- **GitHub Pages**: Push to a repository and enable GitHub Pages under Settings → Pages.
- **Vercel / Netlify / Cloudflare Pages**: Connect your Git repository or drag-and-drop the folder directly for instant global CDN hosting with automatic SSL.
